01 · SDK · Hermes L2 Suite

Hermes L2 Suite — unified Near-Dup SDK, three tiers

Commercial pack hermes-l2-suite: one CLI pipeline (hybrid-verify --tier), early-exit on Pro, one license tick per match. Sibling freezes remain isolated R&D trees (base / rotate / angle).

Tier · base

v2.1 near-dup

Same-still after JPEG q40 / messenger recompress and crop cluster best-effort.

Tier · rotate

v2.2 D₄

Cardinal rotate 90° / 180° / 270° and horizontal mirror (flip_h) of the same enrolled still — typical phone / gallery orientation mistakes without a second enroll.

Tier · angle

v2.3 ±15°

Mild in-plane tilt grid (0, ±5, ±10, ±15°) + advisory geometry_status (green / orange / red). Not a fraud label.

Sold characteristics

What the suite recovers on the same enrolled still — beyond plain JPEG/crop.

  • Recompress JPEG q40 / messenger re-encode of the enrolled photo.
  • Crop Mild center crop / crop-cluster best-effort (not arbitrary hard crop).
  • Rotate Cardinal turns rot90 / rot180 / rot270 — phone landscape vs studio portrait without manual re-upload.
  • Mirror Horizontal flip (selfie-mirror / export flip) recovered in the D₄ orbit.
  • Mild tilt In-plane ±15° (handheld document / shelf photo). Beyond that: advisory only, not sold recover.
  • Quota economy Full cascade costs 1 license tick — no separate bill for rotate then tilt.

02 · Application · Near-Dup use cases

Where Hermes L2 Suite fits

Same-still structural check inside a closed workflow — before a human spends time on a claim pack or listing dispute. Not open-web search. Not biometrics.

Insurance / claims photo packs

Enroll studio or first-notice stills. Score later phone JPEGs, messenger forwards, rotated gallery exports, and mildly tilted handheld shots of that same asset before adjuster review.

Marketplace / listing media

Tie a listing ID to an enrolled product card or SKU photo. Catch “different still” uploads early; accept orientation flips and recompress without forcing sellers to re-shoot.

Intake / back-office QA

Gate multi-photo sessions: same passport, several probes — advisory consensus for operators, not an automatic deny rule.

On-prem / regulated perimeter

Media never needs a vendor cloud hop. Fits СБ / CISO air-gap reviews: soft-lock license, named volume, optional local audit only.

03 · Ops leverage

Time and cost levers

Honest operational gains — not a promised ROI spreadsheet. Pilot measures your own minutes and false-reject rate.

  • Fewer re-asks Rotated / mirrored / mildly tilted phone photos of the enrolled still no longer force a “please re-upload upright” loop — fewer tickets and callbacks.
  • Faster triage One REST match returns verdict + tier + orientation + geometry advisory; operators open hard cases first instead of eyeballing every JPEG.
  • License economy Base + rotate + angle in one tick — you do not burn three quotas to recover orientation then tilt.
  • Infra cost On-prem Docker: no per-image cloud egress / SaaS OCR bill for this check; media stays on your volume (СБ-friendly).
  • False-accept control Lab hard-alien gate 0/48 false Pro — fewer “wrong still passed” escalations that cost investigation hours.

During the closed pilot, track: minutes to first match, share of rotated/tilted probes that stay Pro without re-shoot, and operator time on alien rejects. Those become your internal savings model — we do not invent a universal %.

05 · Security & compliance

For CISO / IT / СБ

  • Egress Zero product phone-home. No cloud telemetry of images, scores, or quota. Optional audit is local JSONL on the named volume only.
  • License Ed25519 signed license + HMAC quota state. Soft-lock only (wipe: false). Exhausted → HTTP 402. Default pilot: 1000 matches / 14 days.
  • Atomicity Exclusive flock on license_state.json.lock. Mount /data as Docker named volume hermes-l2-suite-poc-data — not a host-file bind of the state JSON.
  • Feedback Partner returns filled report template (+ optional local audit summary). Vendor does not pull data from the pilot host.
