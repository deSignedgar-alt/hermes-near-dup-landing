01 · Architecture

The stack

No SaaS hop. One container. Rust does the math; Python only shuttles HTTP.

Rust core

hermes_fleur_cli

Release binary for hybrid-enroll / hybrid-verify / hybrid-session. L2 grid-tile structural match. License gate + flock quota in-process.

Python gateway

gateway.py

Thin ThreadingHTTPServer on 0.0.0.0:8787. Multipart in → subprocess CLI → JSON out. No business logic rewrite in the proxy.

Packaging

Docker native

Multi-stage image. Named volume for /data (quota flock). License mount ro. Scan with Trivy / Docker Scout like any other artifact.

02 · Security & compliance

For CISO / IT

  • Egress Zero product phone-home. Container designed for closed network. Media stays on the customer host.
  • License Ed25519 signed license + HMAC quota state. Soft-lock only (wipe: false). Exhausted → HTTP 402.
  • Atomicity Exclusive flock on license_state.json.lock. Mount /data as a Docker named volume — not a host-file bind of the state JSON.
  • Lab floor Freeze: JPEG q40 8/8 Pro; crop10 (~64% remaining) 5/8 Pro. Not any crop. Not rotation. Not auto-deny.
