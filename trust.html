Deployment guarantees

Short facts for security review of the On-Prem L2 Near-Dup Gateway (v2.1-near-dup). Advisory scores only — not a fraud oracle, not Face Soft, not auto-deny.

Air-gap posture

  • Product gateway listens on the customer host (default loopback / private network).
  • No required SaaS hop for enroll / match / session.
  • Designed so media and scores stay on infrastructure you control.

Zero product telemetry

  • No phone-home of images, scores, or license counters to the vendor.
  • Evaluation pack does not embed cloud analytics SDKs.
  • Outbound access is a customer network policy choice — not a product dependency.

Local volume control

  • Quota / license state lives under /data inside the container.
  • Mount /data as a Docker named volume (e.g. hermes-v21-poc-data).
  • Do not bind-mount a host file onto license_state.json — flock behavior on file binds is unreliable.
  • You retain the volume; wiping the container does not require shipping media back to the vendor.

License soft-lock

  • Ed25519-signed trial license + HMAC-protected quota state.
  • Exhausted quota → HTTP 402, wipe: false (soft-lock only).
  • No product wipe of customer media or vault enrollments on expiry / exhaustion.
  • Default closed trial: 10 matches / 14 days (whichever binds first per signed license).

What we do not claim

  • No biometrics / Face Soft
  • No open-web reverse image search
  • No auto payout deny / auto takedown
  • No sold claim for arbitrary crop / rotation / affine

For a closed evaluation, use the lightweight PoC agreement so legal can clear a 14-day / 10-match trial without a full MSA.
